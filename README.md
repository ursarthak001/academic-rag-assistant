# Academic RAG Assistant
 
Academic RAG Assistant is an end-to-end Retrieval-Augmented Generation (RAG) application designed to answer questions from academic research papers. The system automatically retrieves research papers from arXiv, extracts and processes PDF content, generates semantic embeddings, performs efficient vector-based retrieval using FAISS, and produces grounded responses through Groq LLM.
 
## Key Features
 
- Automated academic paper retrieval from arXiv
- PDF text extraction and preprocessing
- Context-preserving text chunking
- Semantic embeddings using SentenceTransformers
- High-performance vector search with FAISS
- Context-aware answer generation using Groq LLM
- Source attribution for improved transparency and trustworthiness
 
## Technology Stack
 
- Python
- SentenceTransformers
- FAISS
- PyPDF
- arXiv API
- NumPy
- Groq LLM
 
## System Architecture
 
Academic Papers → PDF Processing → Text Chunking → Embedding Generation → FAISS Vector Index → Context Retrieval → LLM Response Generation → Source-Cited Answers
